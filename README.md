# DEMO — магазин подписок

Демонстрационный React-сайт для GitHub Pages. Сервисы и цены вымышлены, оплаты нет.

## Данные и вход

Кнопка входа открывает локальный демоаккаунт, без авторизации ChatGPT и без паролей. Профиль, избранное, заказы и тестовые обращения хранятся только в localStorage текущего браузера. Это не серверная база; данные не синхронизируются между устройствами и могут исчезнуть после очистки браузера. Реальные подписки не выдаются, обращения никому не отправляются.

## Разработка

Node.js 22.13+.

```sh
npm install
npm run dev
npm run build
```

Сборка лежит в docs/. Pages публикует ветку main, папку /docs. После изменений пересоберите сайт и закоммитьте src/ и docs/. Пути относительные, сайт работает в подпапке репозитория.
